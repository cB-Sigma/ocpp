# OCPP 1.6 JSON schemas and WSDLs (Open Charge Alliance)

Unmodified copies from the Open Charge Alliance's OCPP 1.6 documentation package
(`OCPP_1.6_documentation.zip`, packaged 2025-04-29,
<https://openchargealliance.org/protocols/open-charge-point-protocol/>):

- `schemas/`: every file of `schemas/json` (OCPP-J 1.6 JSON schemas, draft-04).
- `wsdl/`: the two WSDLs of `schemas/soap` (OCPP-S 1.6 Central System and Charge Point services).
