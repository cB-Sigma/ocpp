# OCPP 2.1 JSON schemas and device model appendices (Open Charge Alliance)

Unmodified copies from the Open Charge Alliance's OCPP 2.1 document set
(<https://openchargealliance.org/protocols/open-charge-point-protocol/>):

- `schemas/`: every file of `OCPP-2.1_part3_JSON_schemas.zip` (OCPP 2.1 part 3, JSON schemas, 2025-01-23).
- `appendices/`: the CSV files of `Appendices_CSV_v2.1.zip` (OCPP 2.1 Edition 2 part 2 appendices, 2025-12-03).
